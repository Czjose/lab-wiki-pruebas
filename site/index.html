    Caja negra

    Solo ves lo que entra y lo que sale. Con 7 noches, cliente VIP y un total de 300,00, la especificación dice que el resultado debe ser 250,00: si coincide, la prueba pasa. No importa cómo esté escrito el código.

    • Se basa en: la especificación de requisitos.
    • Técnicas: partición de equivalencia, valores límite, tablas de decisión.
    • La puede hacer: cualquiera que entienda los requisitos.

    Caja blanca

    Ahora ves el código: dos decisiones if, cuatro ramas y una complejidad ciclomática de 3. La pregunta cambia de "¿la salida es correcta?" a "¿mis pruebas recorrieron cada rama?".

    • Se basa en: la estructura interna del código.
    • Técnicas: cobertura de sentencias, de ramas y de caminos.
    • La puede hacer: quien sabe programar, normalmente el desarrollador.

    Ficha de herramienta

    JUnit 5

    El framework con el que se escriben todos los ejemplos de este glosario.

    ¿Qué es?

    JUnit 5 es el framework de pruebas unitarias más usado en Java. Permite escribir pruebas como métodos normales, ejecutarlas automáticamente desde el IDE, Maven o Gradle, y obtener un informe de cuáles pasaron y cuáles fallaron. Su motor de ejecución se llama JUnit Jupiter.

    Anotaciones básicas

    • @Test: marca un método como prueba.
    • @BeforeEach: se ejecuta antes de cada prueba; sirve para preparar objetos limpios y que una prueba no contamine a la otra.
    • @DisplayName: da a la prueba un nombre legible que aparece en el informe.

    Aserciones

    • assertEquals(esperado, obtenido): comprueba que dos valores son iguales (con un margen para decimales).
    • assertTrue(condición): comprueba que una condición se cumple.
    • assertThrows(Excepción.class, código): comprueba que el código lanza la excepción esperada.

    Relación con el glosario

    Es la herramienta natural de la prueba unitaria. Combinada con JaCoCo mide la cobertura que exige la caja blanca, y también sirve para pruebas de integración cuando se conectan módulos reales, como el servicio de reservas y una base de datos de prueba.

    import static org.junit.jupiter.api.Assertions.*;

import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;

@DisplayName("Cálculo de la estadía")
class CalculadoraEstadiaTest {

    private CalculadoraEstadia calc;

    @BeforeEach
    void preparar() {
        // Objeto nuevo antes de cada prueba
        calc = new CalculadoraEstadia();
    }

    @Test
    @DisplayName("3 noches a 50,00 cuestan 150,00")
    void totalBasico() {
        assertEquals(150.0, calc.calcularTotal(3, 50.0), 0.001);
    }

    @Test
    @DisplayName("El total nunca es negativo")
    void totalNoNegativo() {
        assertTrue(calc.calcularTotal(1, 0.0) >= 0);
    }

    @Test
    @DisplayName("0 noches lanza una excepción")
    void ceroNoches() {
        assertThrows(IllegalArgumentException.class,
                () -> calc.calcularTotal(0, 50.0));
    }
}
